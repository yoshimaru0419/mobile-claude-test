# 再開用の進捗ファイル

利用制限（目安: 85% 超）やセッション終了で中断しても、正常に再開できるようにするための仕様。

## 方針
- 進捗の真実は **Jira**。進捗ファイルは、その「写し」と「次の一手」を持つ補助。
- 進捗ファイルは、タスクの完了ごと、および利用制限が 85% を超えたときに更新する。
- 更新したら、すぐ push する（コンテナは使い捨てのため）。

## 置き場所
- 作業用ブランチ `claude/progress-state` の `progress.md`（雛形: `progress.template.md`）。
- このブランチは、PR にもマージにも使わない。

## 記録する項目
| 項目 | 内容 |
| --- | --- |
| 現在 | 作業中のタスクと、次の手順 |
| 再開手順 | 再開時に最初にやること |
| PR | ブランチごとの PR 番号 |
| タスク | Jira キー・工程・ブランチ・件名・状態 |

## 85% に達したとき
1. 作業中のタスクがあれば、途中の変更をコミットして push する（件名に「WIP」を付ける）。
2. 進捗ファイルの「現在」に、中断した作業と次の手順を書く。
3. 進捗ファイルを push して、ユーザーに中断を報告する。

## 再開時
1. `ai-dev-start` スキルで、進捗ファイルと Jira を読む。
2. 内容をユーザーに共有する（どこまで終わり、何から再開するか）。
3. 「進行中」のタスクがあれば、その続きから始める。
