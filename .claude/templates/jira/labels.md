# 工程ラベル一覧

ラベルは、**工程（または作業のまとまり）ごと**に付ける。空白は使えない。

## 開発工程のラベル
| ラベル | 使う場面 |
| --- | --- |
| 要件定義 | 要件の整理、要件定義書の作成 |
| 基本設計 | 画面・構成・モジュールの設計 |
| 詳細設計 | 処理・状態遷移・インターフェースの設計 |
| 実装 | コードの実装 |
| 単体テスト | 単体テストの作成・実行・報告 |

## 仕組みづくりのラベル（AI駆動開発の基盤づくり）
| ラベル | 使う場面 |
| --- | --- |
| 基盤 | CLAUDE.md、台帳、環境変数、進捗ファイル |
| ルール | `.claude/rules/` |
| テンプレート | `.claude/templates/` |
| エージェント | `.claude/agents/` |
| スキル | `.claude/skills/` |
| フック | `.claude/hooks/`、`settings.json` |

## 粒度と見積もりの目安
- 1タスクは、半日〜2日で終わる大きさにする。
- 見積もりは `30m` `1h` `2h` `1d` のように書く（`1d` = 8時間）。
- 大きすぎる場合は分割する。分割するときは、要件IDの対応漏れがないようにする。
