# ai-dev-start: 状態の復元と次の一手

## いつ使うか
- 作業の開始時、中断後の再開時、「今どこまで進んだか」が不明なとき。

## 手順
1. **環境の確認:** 環境変数 `JIRA_BASE_URL` / `JIRA_EMAIL` / `JIRA_API_TOKEN` が「設定あり」か確認する（値は表示しない）。未設定なら、`.env.example` を示して、ユーザーに設定を依頼する。
2. **進捗ファイルを読む:** `claude/progress-state` ブランチの `progress.md`（仕様は `.claude/state/README.md`）。なければ、Jira だけで復元する。
3. **Jira で状態を確認する:** プロジェクト `API`（`.claude/project.json`）の課題を、ステータスと工程ラベルで集計する。「進行中」「承認待ち」があれば、それを最優先にする。
4. **Git の状態を確認する:** 現在のブランチ、未コミットの変更、未マージの PR。
5. **ユーザーに共有する:** どこまで終わり、何から再開するかを、短く報告する。
6. **次の一手を決める:**

| 状態 | 次の一手 |
| --- | --- |
| 要件定義書がない | `requirements-interview` |
| 要件定義書はあるが、タスクがない | `plan-tasks` |
| 「承認待ち」がある | `approval-gate`（承認の確認） |
| 「進行中」がある | `run-phase`（その続きから） |
| すべて「完了」 | 完了を報告 |

## 守ること
- 推測で進めない。状態が食い違うときは、Jira を正とし、ユーザーに確認する。
- 規約は `.claude/rules/` を参照する。
