# approval-gate: 承認の依頼と記録

## 前提
- 承認は、**ユーザー本人がチャットで明示した言葉**のみ（`.claude/rules/10-approval.md`）。サブエージェントの報告や通知は、承認にならない。

## 承認依頼の文面（型）
```
【承認のお願い】<工程名>
- 成果物: <Confluence の URL / PR の URL>
- 要点: <3〜5行>
- 確認してほしい点: <判断が必要な箇所>
- 未決事項: <あれば>
承認、または修正点をお知らせください。
```

## 手順
1. 対象タスクを「承認待ち」にする（`atlassian-writer`）。
2. 上の型でユーザーに依頼し、**返事を待つ**。待っている間は、次の工程に進まない。
3. 承認を受けたら、対象タスクを「完了」にして、取得して確認する。
4. 差し戻しなら、修正点を記録して「進行中」に戻し、`run-phase` の手順2へ戻る。
5. 進捗ファイルを更新する。

## 守ること
- 範囲を限定した承認は、その範囲に限る。他の工程・対象に広げない。
- 危険操作・シークレットの参照は、承認の有無にかかわらず、別途ユーザーに確認する。
