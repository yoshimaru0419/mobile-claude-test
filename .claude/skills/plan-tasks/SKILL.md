# plan-tasks: 全工程のタスク起票

## 前提
- 要件定義書が Confluence にあり、ユーザーに承認されていること。
- 起票は `atlassian-writer` が行う（`jira-ops` の手順）。

## 手順
1. **分解案を作る:** `task-planner` に、要件定義書から全工程のタスク案（JSON）を作らせる。
   - 工程: 基本設計 / 詳細設計 / 実装 / 単体テスト
   - 粒度: 半日〜2日。工程ごとに 2〜5 件程度。実装は機能ごとに分ける。
2. **確認する:**
   - 件数・工程別の件数
   - 全要件IDが、どこかのタスクに対応しているか（漏れなし）
   - 期限が、工程順で、土日・祝日を避けているか
3. **レビューする:** `reviewer` に、分解案を確認させる。指摘は直す。
4. **ユーザーに提示する:** タスク一覧（工程・件名・見積もり・期限）を表で示し、承認を得る（`approval-gate`）。
5. **起票する:** `atlassian-writer` に、`.claude/templates/jira/task.json` の型で起票させる。ラベルは工程ごとに付ける。初期ステータスは「未着手」。
6. **検証する:** 件数、工程ラベルごとの件数、ステータスを取得して確認する。
7. キーの一覧を、進捗ファイルに反映する。

## 守ること
- 起票後に、二重登録がないか確認する（失敗・結果不明のときは、再実行の前に現状を取得する）。
- 既存のタスクの削除は、ユーザーが範囲を示して許可したときだけ。
