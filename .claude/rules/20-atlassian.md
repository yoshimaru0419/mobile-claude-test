# 20-atlassian: Jira / Confluence 操作の規約

## 前提
- 認証は環境変数（`JIRA_BASE_URL` / `JIRA_EMAIL` / `JIRA_API_TOKEN`）。値を表示・記録しない。
- 書き込みは `atlassian-writer` エージェントが行う。手順と見本は `jira-ops` / `confluence-ops` スキルを参照する。
- 識別子（プロジェクトキー、スペースID、ページID）は `.claude/project.json` を参照する。

## Jira
- 課題タイプは「タスク」。1タスクは、半日〜2日で終わる粒度にする。
- **ラベルは工程ごとに付ける**（`project.json` の `phaseLabels`、または作業のまとまりの名前）。
- ステータスの対応:

| 状況 | ステータス |
| --- | --- |
| 未着手 | To Do |
| 進行中 | 進行中 |
| 承認待ち | レビュー中 |
| 完了 | 完了 |

- 説明欄は ADF 形式の JSON。【目的】【成果物】【作業内容】を入れる。
- 見積もりは `timetracking.originalEstimate`（例: `2h`、`1d`）。

## Confluence
- 本文はストレージ形式（XML 系）。`&divide;` などの HTML 文字参照は使えない。実際の文字を使う。
- 登録前に、同名ページがないか確認する。整形式（XML として正しいか）も確認する。

## 書き込みの鉄則
1. **書き込み後は、必ず取得して検証する**（件数・ラベル・ステータス・本文の章立て）。
2. **結果が見えないとき、または失敗したときは、再実行の前に現状を確認する**（二重登録を避ける）。
3. 応答の整形は、本文とステータスコードを分けて取得する。
4. 削除・一括変更は、ユーザーの許可がある範囲だけ。
